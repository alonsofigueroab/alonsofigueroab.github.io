# Sitio en GitHub Pages

Sitio estático básico construido con HTML y CSS.

## Publicar

1. Sube estos archivos a la rama `main` de tu repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona `main` y la carpeta `/(root)`, y guarda.

GitHub Pages publicará `index.html`. La URL aparecerá en la misma sección de Pages. Puedes editar el título, el texto y el enlace en `index.html`, y los colores y diseño en `assets/css/style.css`.
